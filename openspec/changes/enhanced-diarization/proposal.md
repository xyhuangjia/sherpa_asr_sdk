# 提案：增强说话人分离功能

## 概述

增强 `AsrDiarizationManager` 的说话人分离能力，支持：
1. **关联已注册说话人**：会议中自动识别已注册用户（如"张三"），而非生成匿名标签（"Speaker 1")
2. **说话人重识别**：支持说话人中途离开后返回时，识别为同一人，避免重复创建标签

## 当前问题

| 问题 | 说明 |
|------|------|
| 标签无语义 | "Speaker 1" 无法关联具体人名 |
| 不跨会话 | 每次会议重新计数，历史丢失 |
| 未关联注册 | 已注册的说话人（如"张三"）无法自动匹配 |
| 无重识别 | 说话人离开后返回会创建新标签 |

## 目标

- 会议中张三发言 → 显示 "张三"（而非 "Speaker 1")
- 张三离开 5 分钟后返回 → 继续识别为 "张三"
- 已匹配的匿名说话人可升级为已注册用户

## 非目标

- 不改变 SpeakerManager 的注册流程
- 不支持跨不同会议的说话人追踪（仅当前会话内）
- 不增加用户交互式匹配界面（自动匹配）

## 方案

采用分层匹配策略：

```
第一层：匹配已注册说话人 (threshold: 0.7，严格)
  → 成功：返回 "张三"
  → 失败：进入下一层

第二层：匹配会议中已出现说话人 (threshold: 0.5，宽松)
  → 成功：返回 "Speaker 1"（或已关联的 "张三"）
  → 失败：进入下一层

第三层：创建新说话人
  → 返回 "Speaker N"
```

关键设计：
- **A1**: 匹配成功直接显示真实姓名
- **D1**: 每个说话人存储多个 embedding，取最佳匹配
- **T1**: 每个语音段实时匹配

## 影响范围

| 文件 | 变化 |
|------|------|
| `asr_diarizer.dart` | 重构匹配逻辑，支持分层匹配、多 embedding |
| `asr_diarization_manager.dart` | 添加 SpeakerManager 引用，传递已注册数据 |
| `asr_diarization_config.dart` | 新增配置项 |
| `asr_service.dart` | 传递 SpeakerManager 给 DiarizationManager |

## 风险

| 风险 | 缓解措施 |
|------|----------|
| 已注册说话人较多时匹配耗时 | 限制同时检查数量，或使用批量距离计算 |
| 偶然匹配错误（张三→李四） | 第一层使用较高阈值（0.7） |
| embedding 累积过多 | 设置上限（如最多存 5 个），定期清理旧数据 |

## 成功标准

- 已注册说话人能被正确识别（准确率 > 90%）
- 同一说话人离开返回后能正确重识别（准确率 > 80%）
- 不影响现有 API 兼容性
